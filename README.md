# iAx · inteliAxencia

Sitio web de iAx, digitalización práctica para organizaciones del ámbito laboral y jurídico: despachos laboralistas, graduados sociales, sindicatos, colegios profesionales, patronales y empresas.

## Estado

En desarrollo. El prototipo estático vive en index.html y sirve de referencia visual; la migración a componentes de Astro está pendiente. La fuente de verdad del sitio es src/.

## Stack

Astro sobre Cloudflare Workers, con Tailwind v4 y Node 24. El entorno de desarrollo va en un Dev Container sobre Podman.

## Para desarrollar

Empieza por CONTRIBUTING.md. La guía de instalación está en docs/guia-instalacion.md y te deja el entorno montado desde cero.
